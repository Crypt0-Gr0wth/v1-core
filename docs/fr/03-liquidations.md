# 3. Liquidations

La liquidation transforme une insuffisance de garantie en règlement contrôlé. Les paramètres de marché, frais et délais doivent rester cohérents pour éviter les sorties injustes.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
